이번 자료의 범위: 2026.10.21 공식 공개 본문을 수집했습니다. 법령은 전체 조문과 화면에 제공된 부칙, 판례는 공개 판시사항·전문, HUG는 해당 안내 페이지 본문입니다. 첨부 별표·별지·약관·서식 파일과 실제 내부 기준은 포함하지 않습니다. 원문 URL·시행일·수집 범위는 TXT 머리말과 목록에 있습니다.

내 NotebookLM에 45개씩 등록하기 · 30분

  1. 세 ZIP을 내려받아 압축을 풉니다. 본인 계정에서 A · 직원 지식검색, B · 민원 답변 지원, C · 서류 검토 지원 노트북을 따로 만듭니다.
  2. 각 ZIP의 sources 폴더 안 TXT 45개만 파일로 올립니다. README·목록 CSV·프롬프트·기록지는 소스로 등록하지 않습니다. 5~10개씩 나눠 올려도 됩니다.
  3. 파일 처리 완료를 기다려 각각 45개인지 확인합니다. 실패한 파일만 다시 올리고, 같은 원문 URL을 추가 등록하지 않습니다.
  4. 목록 CSV의 ID와 실제 소스 이름을 맞춥니다. 소스를 직접 열어 법령의 제1조·부칙, 판례의 사건번호·전문, HUG 안내의 조건 문장이 읽히는지 각 1개씩 확인합니다.
  5. README와 prompts.txt는 옆에 열어 두고, worksheet.txt는 실행 결과를 기록하는 데 씁니다. 역할 지시문은 채팅 또는 맞춤 지시로 사용합니다.

예상 상태: 세 노트북의 처리 완료 소스가 각각 45개입니다. 제목만 보이는 상태와 본문 처리가 끝난 상태를 구분하세요.

막혔을 때: 업로드가 중단되면 파일 수를 줄여 재시도합니다. 처리되지 않은 ID를 기록합니다. 계정 한도가 부족하면 조별로 A/B/C 역할을 나누고, 자신의 실행 범위를 기록합니다. 계정 접근이 불가하면 짝의 원문 검증을 맡되 개인 실행 완료로 표시하지 않습니다.

표준 계정의 노트북당 소스 한도는 수업 전 본인 계정에서 확인하세요. 45개 편성은 50개 한도 환경에서 추가 실습용 5칸을 남기는 구성입니다. 프롬프트와 기록지를 소스로 넣으면 이 여유가 줄어듭니다. Google 공식 한도 안내

핵심 5개와 전체 45개를 비교하기 · 25분

노트북 A에서 먼저 민법·주택임대차보호법·임차권등기명령 절차 규칙·2005다4529·2024다261989 다섯 소스만 선택합니다. 아래 질문을 실행하고 응답과 인용을 저장하세요. 이어 전체 45개를 선택하고 같은 질문으로 다시 실행합니다.

공통 역할 지시문
제공된 소스를 우선 근거로 삼아 답하되, 답을 지지하는 문서 ID·제목·조문 또는 판례 문장과 인용을 붙여주세요. 자료에 없는 사실은 확인 불가로 적고 추가 자료를 요청하세요. 법령 시행일·사건 발생 시점·판례의 사실관계를 구분하세요. HUG 웹 안내의 확인일은 적용 약관의 시행일과 같지 않습니다. 법령과 공개 상품 안내를 HUG 내부 규정으로 취급하지 마세요. 여러 자료가 다르면 차이와 확인할 담당자를 적으세요. 법률·행정절차의 개별 업무 적용 여부와 보증 승인·지급·서류 진위는 사람이 판단할 사항으로 남겨주세요.
두 조건에서 동일하게 실행할 질문
임차권등기 말소와 보증금 반환은 어느 쪽을 먼저 해야 하나요? 2005다4529와 2024다261989의 등기 근거·사실관계·별도 약정을 비교하고, 일반화할 수 없는 조건을 밝혀주세요. 문서 ID·조문·원문 문장을 함께 제시하세요.

판례 TXT 제목에 사건번호가 있습니다. 선택 후 소스 목록에서 다섯 개만 체크됐는지 직접 확인합니다. 다른 서비스에서 소스를 선택할 수 없으면 새 대화 두 개에 해당 파일만 따로 제공합니다.

비교 기록: 선택 문서 ID → 첫 답 → 전체 선택 후 답 → 인용한 문서 → 빠진 조건 → 직접 고친 문장. 전체 45개가 더 정확했다고 미리 정하지 않습니다. 답이 같으면 근거 선택과 불필요한 내용이 달라졌는지 봅니다. 이 비교만으로 내부 청크 크기나 Recall@k를 측정한 것은 아닙니다.
