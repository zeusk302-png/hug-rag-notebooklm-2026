한 가지 설정을 바꾸고 다시 시험하세요.

  1. 같은 질문 세트와 문서 버전으로 기준 결과를 저장합니다.
  2. 청크 단위 또는 검색 방식 중 하나만 바꿉니다.
  3. 필수 근거 누락·잘못된 적용·응답시간을 비교합니다.
  4. 개선되지 않은 질문도 남기고 원인을 설명합니다.

운영 허용 기준은 기관 담당자와 정합니다. 평균 점수가 높아도 권한 유출이나 위험한 확약 사례가 남으면 해당 실패를 별도로 해결해야 합니다. 자동 평가의 판정도 표본을 사람이 대조합니다.

서류 검토에는 다른 평가도 필요합니다.

OCR·추출 단계의 날짜·금액·ID 일치, 규칙검사의 누락 탐지, 검색 기준의 버전, 최종 점검표의 근거를 각각 확인합니다. 제출목록에서 찾았다는 사실과 실물 내용·진위가 확인됐다는 사실을 분리합니다.

스스로 확인하기

먼저 답을 생각한 뒤 해설을 펼치세요.

1. 답이 틀리면 무조건 프롬프트부터 고칠까요?

아니요. 필요한 근거가 색인·검색 후보·전달 맥락 어디까지 도달했는지 먼저 봅니다.

2. 평가 질문에 없는 새 질문은 괜찮을까요?

한정된 평가 세트는 모든 질문을 보장하지 않습니다. 현장 실패와 새 유형을 추가하고 개정 후에도 다시 시험합니다.

3. 필수 근거 2개 중 1개를 상위 4개에서 찾으면 무엇을 알 수 있나요?

Recall@4는 1/2입니다. 검색의 필수 근거 회수율이며, 생성 답변의 정확도는 별도로 대조합니다.

오류 진단 활동 · 25분

각 사례에서 문제 위치와 다음 행동을 한 가지씩 적습니다. 단정하기에 증거가 부족한 사례에는 추가로 필요한 로그를 적으세요.

사례 카드학생이 판단할 것
D1 · 필요한 조문이 추출본에 없음자료/OCR 문제인지 검색 문제인지
D2 · 추출본·색인에는 있고 검색 후보에는 없음청킹·표현·필터 중 무엇을 더 확인할지
D3 · 후보에 두 판례가 있으나 전달 입력에는 하나만 있음검색 회수와 근거 선택의 차이
D4 · 올바른 근거가 전달됐지만 답은 접수만으로 승인이라 함생성 해석과 업무 조건
D5 · 인용 ID는 있으나 결론을 지지하는 문장이 없음인용 존재와 주장 근거의 차이
D6 · 같은 질문의 답이 다르지만 사용 소스 기록이 없음대화·자료 범위·버전 확인 필요
  1. 개별 분류 5분: 실패 위치와 이유를 씁니다.
  2. 개인 대조 8분: 서로 다른 분류의 증거를 비교합니다.
  3. 평가표 작성 7분: 정상·자료 부족·권한 밖·버전 변경 질문을 적습니다.
  4. 자기 점검 5분: 기준 답과 필수 근거가 실제로 연결되는지 확인합니다.
강사 기준 예시

D1은 자료 추출, D2는 검색 진단, D3는 전달 근거 선택, D4는 생성/적용 조건, D5는 인용 검증입니다. D6은 어떤 자료를 선택했는지와 대화 상태를 확인합니다. D2에서 청킹만 원인이라고 확정할 수는 없으며 필터와 검색 로그도 필요합니다.

자기 AI로 진단한 뒤 사람이 대조하기
아래 실패 사례를 자료 준비 / 검색 / 전달 근거 선택 / 생성 해석 / 인용 검증 / 추가 증거 필요로 분류해줘. 사례마다 근거와 다음 확인 항목을 적어줘. 증거가 부족하면 한 가지 원인으로 단정하지 마.
D1: 필요한 조문이 추출본에 없다.
D2: 추출본·색인에는 있지만 검색 후보에는 없다.
D3: 필요한 두 판례가 후보에는 있지만 생성 입력에는 하나만 있다.
D4: 승인 조건이 근거에 있지만 답은 신청 접수만으로 승인이라고 말한다.
D5: 인용 ID는 있지만 원문 문장이 답의 결론을 지지하지 않는다.
D6: 같은 질문을 두 번 했는데 어떤 문서를 선택했는지 기록하지 않아 답이 다른 이유를 모른다.
